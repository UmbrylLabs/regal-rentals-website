# Payment Security Examples

| Rental subtotal | Credit-card deposit | Debit-card or cash deposit |
|---:|---:|---:|
| $100.00 | $0.00 | $50.00 |
| $250.00 | $0.00 | $125.00 |
| $400.00 | $0.00 | $200.00 |
| $1,000.00 | $0.00 | $500.00 |
| $2,000.00 | $0.00 | $1,000.00 |

Credit-card bookings still require the same valid credit card used for payment to be securely stored on file before equipment release. Debit-card and cash deposits remain exactly 50% of the final confirmed subtotal, with no minimum or maximum.
