# Regal Rentals Website

Upload-ready static website for Regal Rentals.

## Current version

Launching-soon version. This version avoids listing specific rental inventory until real items are ready.

## Files

- `index.html` — homepage
- `styles.css` — responsive styling and animations
- `script.js` — mobile menu, carousel buttons, reveal animation, and email form
- `assets/` — Regal Rentals logo/shield/favicon
- `robots.txt`, `sitemap.xml`, `404.html` — basic site files

## Deploying to Cloudflare Pages

Use these Cloudflare Pages settings:

- Framework preset: None
- Build command: leave blank or use `exit 0`
- Build output directory: `/`
- Production branch: `main`

## Contact form
